# Aulas-Estrut-Dados-II
Contaúdo da matéria de Estrutura de Dados II para os alunos do 4º período do curso de Sistemas de Informção.

### Material teórico
O material teórico é apresentado em aula e fica disponível no AVA.

### Códigos
Os códigos demonstrados aqui tem o objetivo de servir como exemplo e referência, porém, podem não conter todas as funcionálidades mencionadas em sala e não servem como gabarito de nenhuma atividade.

### Dúvidas
Eventuais dúvidas podem ser sanadas durante a aula do contaúdo, no momento de revisão que inicia a aula seguinte ou pelo Fórum de Dúvidas do AVA.
